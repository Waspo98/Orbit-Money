# App Icons

Source collection: [Dazzle Line Icons on SVG Repo](https://www.svgrepo.com/collection/dazzle-line-icons/)

Local adjustments:
- Renamed files for Orbit Money navigation IDs.
- Normalized SVG dimensions to `24x24`.
- Changed strokes to `currentColor` so icons inherit app colors.
- Reduced `stroke-width` from `2` to `1.6` for a lighter app-wide weight.

Check the source collection for additional matching icons before adding icons from another style family.
